# Amazon-Sales-Analysis (亚马逊电商销售数据分析)

## 📌 项目简介
本项目基于阿里云天池的 10 万条亚马逊电商真实交易数据，使用 MySQL 进行数据提取与聚合清洗，最终结合 WPS 完成可视化分析，输出商业洞察报告。

## 📊 核心发现
- **整体业绩**：平台总销售额超 9182 万，总订单量 10 万笔。
- **时间趋势**：整体销售平稳，2024年5月出现销售额最高峰。
- **品类表现**：Electronics（电子）、Sports & Outdoors（运动户外）、Books（图书）为 Top3 营收品类。
- **城市分布**：Denver（丹佛）客单价最高（929.37元），具备高消费潜力。

## 🛠️ 技术栈
- **数据库**：MySQL
- **核心函数**：`SUM`, `COUNT`, `DATE_FORMAT`, `GROUP BY`, `ORDER BY`
- **可视化工具**：WPS 表格
